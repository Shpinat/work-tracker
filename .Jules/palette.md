## 2024-10-24 - Accessible Calendar Days and Shift Details
**Learning:** Screen readers reading out only the numbers of a grid-based calendar view with icon markers create an extremely poor navigation experience. We can massively improve context by providing full descriptive sentences constructed from the day data in `aria-label`.
**Action:** Always provide full sentence `aria-label` descriptions for custom, visual calendar grid cells and list items that use multiple smaller DOM nodes and icons to display information. Ensure you use `aria-hidden="true"` on the internal visual DOM elements when you provide a higher level overarching `aria-label` on their container so that screen readers don't read duplicate, disjointed information.
